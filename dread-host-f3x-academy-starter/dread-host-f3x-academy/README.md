# Dread Host F3X Academy — website starter

This is the first front-end build of the academy. It is a static website that runs in a browser.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

## Publish it
Upload the contents of this folder to a static website host such as GitHub Pages or Netlify. Follow the host's current account and age requirements; if needed, ask a parent/guardian or trusted adult to help set up hosting.

## Current features
- Responsive dark fantasy academy interface
- Dashboard, six training levels, tool library, practice quiz, Hall of Honour
- Demo XP and completion progress saved in the current browser using local storage

## Important limitations
- This is not yet a live hosted website.
- There are no real user accounts, password handling, shared leaderboards, database, instructor permissions, or Roblox integration.
- Demo completion is not proof of practical skill and should not be treated as an official qualification.
- Do not add passwords, API keys, or private Roblox credentials to these files.

## Next development stage
Add a secure backend and database for accounts, roles, progress, instructor verification, and server-side Roblox integration. Keep secrets on the server, never in browser JavaScript.
